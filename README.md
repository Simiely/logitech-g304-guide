# Logitech G304 驱动维护手册

> 罗技 G304 LIGHTSPEED（AA 电池经典款）的驱动选型、安装、配置与排坑记录。
> 遵循 [knowledge-base](https://github.com/Simiely/knowledge-base) 单项目规范维护。

## 这是什么

G304 出厂即插即用，但要改 DPI 档位、回报率、按键分配，就必须装罗技的软件。

麻烦的地方在于：罗技有三套软件都能碰这只鼠标，而它们的能力边界、依赖关系、坑点各不相同，网上流传的版本号和下载链接大量是过期或错的。本仓库把选型过程和实测结论固化下来，避免下次重装系统再踩一遍。

**一句话结论**：经典款 G304 用 **LGS 9.04.49**（老驱动），不要装 G HUB。

## 三套软件怎么选

| | LGS（老驱动） | G HUB（新驱动） | OMM（板载内存管理器） |
|---|---|---|---|
| 状态 | 已停更，最终版 9.04.49 | 持续更新（滚动版本号） | 持续更新，当前 2.6.1749 |
| 体积 | 安装包约 120 MB | 安装包约 69 MB，装完更大 | 13 MB，免安装 |
| 后台常驻 | 是（轻量） | 是（Node.js，社区实测 150–300 MB 内存） | 否，用完即关 |
| 支持经典 G304 | 官方支持 | 支持 | 支持 |
| 支持新款 G304 X | 不支持 | 支持 | 支持（2.6.1749 起） |
| 每程序独立配置 | 支持 | 支持 | 不支持 |
| 宏 | 支持 | 支持 | 不支持 |
| 推送固件更新 | 否 | 是（唯一途径） | 否 |

判据与取舍详见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 安装

1. 下载 [LGS 9.04.49 x64](https://download01.logi.com/web/ftp/pub/techsupport/gaming/LGS_9.04.49_x64_Logitech.exe)
2. 双击安装，UAC 提权；**安装时保持 LIGHTSPEED 接收器插在 USB 口上**（驱动会一起装好）
3. 装完 LGS 会自动以最小化方式启动，无需手动开

**下载后请校验**（官方 CDN 上的旧文件很容易被第三方站点冒充）：

- 文件大小：`125,787,696` 字节
- 数字签名状态：`Valid`，签名者 `CN=Logitech Inc`，签发机构 `DigiCert EV Code Signing CA (SHA2)`
- SHA256：`6DB9F6442D46FBDE0953F8BFBC36BD714E5E31A62F927563594CAFD60724D3E0`

校验方法见 [DEVELOPMENT.md](DEVELOPMENT.md) 问题 2。

## 快速开始

装完 LGS 后：

1. 首页确认 G304 被识别
2. 调整 DPI 档位（G304 范围 100–12000，50 一档）、回报率（125/250/500/1000 Hz）、按键分配
3. 决定用哪种模式（见下）

### 两种模式必须二选一

LGS 首页有一个蓝色滑块，左右两档**互斥**：

- **板载内存模式**（拨左）：设置写进鼠标，换电脑免装驱动；但全机只有一套配置，宏受限
- **自动游戏检测**（拨右）：每个程序一套独立配置，宏完整；但 LGS 必须常驻后台

G304 只有 **1 个板载槽位**，所以板载模式下无法存多套配置手动切换。

## 常见误区

- **LGS 最终版不是 9.02.65，是 9.04.49**。9.02.65 已从官方 CDN 下架（403），9.02.74 是 Win7/8 分支。
- **OMM 不是「免 G HUB 的替代品」**。罗技官方 FAQ 写明它 *relies on G HUB for functionality*，且必须先把鼠标切到板载内存模式才认得到设备。
- **板载模式存不了靠软件模拟的功能**。典型例子：在 G HUB 里把中键设为「双击」可用，写进板载后直接失效。
- **不要在 LGS 和 G HUB 之外再装另一套**。两套完整驱动同时存在会抢设备控制权，导致设置不生效。
